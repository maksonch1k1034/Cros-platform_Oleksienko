# Матеріали лабораторної роботи №3

### Архітектурний стиль та архітектурна діаграма
Для програмної системи «Застосунок для кав’ярні» обрано трирівневу (3-tier) клієнт-серверну архітектуру. На діаграмі зображено взаємодію між вебклієнтом (HTML/CSS/JS), серверною частиною на Node.js та реляційною базою даних PostgreSQL 16. Також відображено інтеграцію із зовнішнім платіжним шлюзом для обробки безготівкової оплати замовлень.

### ER-діаграма
ER-діаграма описує концептуальну модель даних системи та зв'язки між сутностями. У базі даних виділено 5 основних таблиць: Користувач, Замовлення, Позиція_замовлення, Товар та Категорія. Усі відношення реалізовано за типом «один до багатьох» (1:N) із визначеними первинними та зовнішніми ключами.

### Каркас та макет UX/UI
Каркас (Wireframe) та макет (Mockup) відображають інформаційну архітектуру та візуальне оформлення застосунку «Coffee first». Вони містять 4 основні екрани: авторизація, меню клієнта, кошик з оформленням та екран замовлень для баристи. Дизайн виконано у теплій кавовій палітрі з дотриманням вимог стандарту ISO 9241.
